Drafts written on the school’s own machine

Draft a family summary, or ask a question about your caseload.

No student data leaves the server. Off until a school switches it on.

The owner asked to prototype with local models. Text runs through a model server on localhost, and the code refuses any other host. Every output is a labelled draft; nothing is shared until the BCBA publishes. These drafts came from Gemma 4 26B on the owner's llama.cpp server in about seven seconds; Ollama with mistral-nemo 12B is the fallback. Neither was chosen by comparison, and local models still overstate or invent a sentence, so the review step matters. Voice notes use Whisper small.en through a whisper.cpp server. The architecture section shows both.
