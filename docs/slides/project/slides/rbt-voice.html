Dictate the session note

Tap Dictate, speak, tap Stop. The text lands in the note about a second later.

A Whisper model on the school’s own machine does the transcription. The audio is not kept.

Tested with synthetic speech only, not a real voice, a noisy classroom or a phone.

The button appears only when the school has switched voice notes on and the server has a local speech model. It works online only, in English, and only on the session-end note for now. Model: Whisper small.en through a whisper.cpp server.
