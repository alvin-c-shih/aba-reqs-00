Architecture

What runs, and on which port

API on 8010, web on 5173, PostgreSQL on a local socket.

Optional model helpers: llama.cpp on 8080 or Ollama on 11434 for text, whisper.cpp on 8178 for speech.

Settings come from one git-ignored file. State lives in PostgreSQL plus three folders under data: uploaded media, the speech model, and a temporary folder for audio being converted. There is no cache, queue or search index. Demo conveniences are gated on the server by environment.
