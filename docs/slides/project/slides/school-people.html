School admin

Accounts start with a one-time password

Shown once to the admin, then never again. The new person must choose their own at first sign-in.

Deactivating ends access at once and keeps history.

Admins create all accounts; there is no self-registration. A local install has no email service, so the temporary password is handed over in person or by phone. Five failed sign-ins lock an account for fifteen minutes; an admin can reset and unlock from the same menu.
