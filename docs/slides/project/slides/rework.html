What changed

From a contradictory spec to a working system

Built

A real app for six roles: API, web app, design system, database, resettable demo data.

Before: 13,000 lines of documents and one clickable mock-up.

Verified

36 API tests and a scripted walkthrough that drives every role, including offline recording, a two-device takeover and local-model drafts.

The walkthrough produced the 78 screenshots this deck draws from.

Recorded

18 decision records, an assumptions log, six architecture diagrams and a guide for future agents.

The 2025 spec is archived, not deleted.

The October review found the spec contradicted the owner's recorded answers in about fifteen places. Rather than patch documents, this rework builds Phase 1 as the tested core and Phases 2 to 4 as first working versions, adopts the review's recommended defaults, and writes down every decision. Not yet done: browser coverage beyond Chromium, an accessibility audit with a screen reader, and deployment concerns such as TLS and backups.
