Demo mode

Stateful, and one click to reset

Pick a persona, no password. Everything you change is real and saved.

Reset demo restores the starting data, with dates recalculated from today.

Demo data lives in a database, as the owner required, in its own environment so it never mixes with real records. Persona sign-in and reset are refused by the server outside Demo, Dev and QA; in production the routes do not exist. The banner is always visible: purple for Demo, green for Dev, amber for QA, neutral for Prod.
