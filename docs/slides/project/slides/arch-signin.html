Architecture

One chain for every sign-in

Throttle, lock, password, second factor, session, audit.

A wrong code counts toward the lock like a wrong password.

Two-factor is optional per person today and should be enforced for staff before real data. Enrolment uses a typed key, not a QR code. The authenticator secret is stored unencrypted in the database, so it relies on disk encryption. There is no password reset by email.
