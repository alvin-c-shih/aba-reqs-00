Architecture · prototype

Local models behind six gates

Text: llama.cpp server running Gemma 4 26B, with Ollama and mistral-nemo 12B as fallback. Speech: whisper.cpp running Whisper small.en.

All listen on this machine only. Every output is a draft.

Text is tried first on the owner's llama.cpp server on port 8080, set by one line of configuration; a summary draft took about seven seconds. If that server is not running, the app falls back to Ollama 0.11.7 on port 11434, where the first answer took about fifty seconds. Speech uses a whisper.cpp server 1.9.5 on port 8178 with a 488 megabyte model. No model was chosen by comparison; each was already on the machine. Measured on an Apple M1 Max with 64 gigabytes.
