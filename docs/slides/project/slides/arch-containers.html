Architecture

Three things to run

One web app, one API process, one PostgreSQL database per environment.

No cache, queue or second database. Two local-model helpers are optional.

All thirteen architecture diagrams are saved in docs/architecture/diagrams as SVG and PNG, generated by make diagrams from one script, and explained in docs/architecture/README.md. The 2025 architecture drew a gateway, five services and four data stores for about a hundred students. This is right-sized: the whole backend is about twenty-eight hundred lines. The API connects to the database as an unprivileged role; a separate owner role is used only for migrations and demo reset.
