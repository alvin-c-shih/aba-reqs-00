This closes a gap against the original requirements, which asked for automated phase-change detection. It is plain statistics, not a trained model: a program has ten to thirty sessions, and a clinician must be able to see why. A steady ramp is not flagged, only a jump. The dashed blue line is the forecast: about three to four more sessions to criterion at the current rate.
