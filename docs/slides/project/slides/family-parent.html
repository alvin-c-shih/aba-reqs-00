Parent · Phase 3

Families see what the team chooses to share

Goals in plain words: what is counted, whether lower or higher is better, and which way it is moving.

Never sessions, staff names on data, or clinical notes.

A falling count of a behaviour reads as progress, because each goal is judged against its own direction. Each program has a family-friendly name, so a parent reads “Asking for things he wants”, not “Manding”. What they see is a frozen publication, not a window onto live clinical data. The school office invites parents; the BCBA decides what each can do.
