Programs with a rule the system can check

Mastery is a sentence with numbers: a value in N of the last M sessions.

The form has undo and redo, so trying a change costs nothing.

The old spec allowed free-text mastery criteria, which cannot be evaluated. Undo and redo for forms was an explicit owner request. Typing in one field counts as one undo step; changing another field starts a new one. Nothing is saved until Save.
