# ABA Data Collection & Analysis System - Requirements Questions

## Core Purpose & Users

1. **Who are the primary users?** (BCBAs, RBTs, parents, clinic administrators, school staff?)

All. This is a full-system for a school.

2. **What setting will this be used in?** (clinic, home-based therapy, school, all of the above?)

School and home.

3. **Is this a web app, mobile app, desktop app, or multi-platform?**

Web and mobile.

## Data Collection Features

4. **What types of data collection methods do you need?**
   - Frequency/event recording
   - Duration recording
   - Interval recording (partial, whole, momentary time sampling)
   - ABC (Antecedent-Behavior-Consequence) data
   - Trial-by-trial / discrete trial data
   - Task analysis / chaining data
   - Probe data

All.

5. **Do you need real-time data collection** (during sessions) or post-session entry, or both?

Both. Need ability to retroactively edit data.

6. **What behaviors/skills are being tracked?** (skill acquisition programs, behavior reduction targets, both?)

Both.

## Analysis & Reporting

7. **What types of graphs/visualizations do you need?** (line graphs, bar charts, celeration charts, cumulative records?)

All. Plus ability to annotate which treatments were applied in case the student is unresponsive to the original plan and ideation is required.

8. **Do you need automated phase change line detection or trend analysis?**

Yes. Identify when some change is required in curriculum / intervention.

9. **What reports are needed?** (progress reports, insurance/billing reports, parent summaries?)

All.

## Technical & Compliance

10. **Does this need to be HIPAA compliant?** (handling PHI - protected health information)

Yes.

11. **Do you need offline capability** for data collection without internet?

Yes. Should be able to sync up if WiFi is lost.

12. **Any integration requirements?** (existing practice management software, billing systems, EHRs?)

No.

13. **Multi-client/multi-therapist support?** How many users/clients approximately?

100 students, most with 1:1 ratio.

## Existing Work

14. **Is this a greenfield project or are there existing systems/data to integrate with?**

Greenfield.

15. **Do you have a preferred tech stack?**

Easy to maintain while allowing access to advanced features on mobile device (camera, voice, etc.)

## Additional Requirements

*(Please add any other requirements, features, or constraints not covered above)*

Guided tour capability to onboard staff quickly during periods of high turnover.

Demo mode with fake data in a database - not hardwired into the app.

User stories with clear callouts to UI elements.
